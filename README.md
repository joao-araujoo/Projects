## 📖 Sobre Este Repositório

Este espaço funciona como meu laboratório pessoal. Aqui, eu reúno diversos projetos, desde clones de interfaces para treinar CSS, até aplicações full-stack com consumo de APIs e lógica de back-end. O objetivo é manter um registro prático da minha evolução como desenvolvedor.

Cada projeto está contido em sua própria pasta. Para mais detalhes, navegue até o diretório correspondente.

## 🏆 Vitrine de Projetos

Abaixo estão os meus principais projetos, organizados para destacar a variedade de tecnologias e complexidade.
